# Sistema de Información para el Control de Ventas e Inventarios de Repuestos y Accesorios para Bicicletas

## Descripción

Este proyecto corresponde al desarrollo de un **Sistema de Información para el Control de Ventas e Inventarios de Repuestos y Accesorios para Bicicletas**, diseñado para optimizar la administración de los procesos comerciales, el control de inventario y la gestión de clientes.

El sistema se desarrolla con base en la **Especificación de Requisitos de Software (ERS)**, elaborada siguiendo las directrices establecidas por el estándar **ANSI/IEEE 830-1998 - IEEE Recommended Practice for Software Requirements Specifications**, garantizando una documentación estructurada y una adecuada definición de los requisitos funcionales y no funcionales del proyecto.

## Objetivo

Desarrollar una plataforma que permita administrar de manera eficiente las operaciones de una tienda de bicicletas, integrando los procesos de ventas, inventario, administración y atención al cliente en un único sistema.

## Arquitectura del Sistema

El sistema estará organizado en cuatro módulos principales:

### 📋 Gestión Administrativa

Módulo encargado de la administración general del sistema, incluyendo la gestión de usuarios, roles, permisos, configuración del sistema, proveedores y demás procesos administrativos necesarios para el funcionamiento de la aplicación.

### 🛒 Gestión de Ventas

Permite registrar y administrar las ventas de repuestos y accesorios, generar facturas, consultar el historial de ventas y realizar el seguimiento de las transacciones comerciales.

### 📦 Gestión de Bodega

Responsable del control del inventario de productos, incluyendo el registro de entradas y salidas, actualización de existencias, gestión de categorías, control de stock y administración de repuestos y accesorios disponibles.

### 👥 Gestión de Clientes

Facilita la administración de la información de los clientes, permitiendo registrar nuevos clientes, actualizar sus datos, consultar el historial de compras y fortalecer la relación comercial con ellos.

## Características Generales

* Administración centralizada de la información.
* Control de inventario en tiempo real.
* Registro y seguimiento de ventas.
* Gestión de clientes y proveedores.
* Administración de usuarios y permisos.
* Plataforma modular, escalable y de fácil mantenimiento.
